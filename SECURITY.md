# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Email info@cuisine.digital with a description, the affected version and steps to reproduce. We acknowledge reports within five working days and keep you informed until a fix is released.

## Supported versions

Security fixes are released for the latest minor version of `@shopvento/ui`.

## Scope

This package renders storefront components in the browser. Authentication, payment and authorisation are enforced by the Shopvento backend and by the host site's same-origin API proxy. Reports about those parts are welcome at the same address.
